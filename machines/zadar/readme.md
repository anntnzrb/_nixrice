# Zadar

Headless development server for agent sessions and moderate workloads. Its
disk is a spinning HDD: parallel installs, checkouts and builds contend for
seeks, so it is not a build box.

## Hardware

| Component | Specification |
| --- | --- |
| Laptop | ASUS GL502VMK; UEFI BIOS GL502VMK.308 |
| CPU | Intel Core i7-7700HQ, 4 cores / 8 threads |
| RAM | About 12 GB |
| GPU | NVIDIA GeForce GTX 1060 Mobile, 6 GB |
| Disk | HGST Travelstar 7K1000 (HTS721010A9E630), 1 TB, 7200 RPM, serial `JR1000D30WN62E` |
| Ethernet | Realtek r8169, Gigabit |
| Wi-Fi | Intel 8260 |
| Battery | No usable reserve; does not charge with AC present |
